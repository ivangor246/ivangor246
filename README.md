## Featured project

### [Gen Music AI](https://github.com/ivangor246/gen_music_ai)

Cross-platform desktop application for generating multi-instrument music locally with AI.

The application runs entirely on the CPU without cloud services or a dedicated GPU. Users can configure instruments and generation parameters, preview compositions and export the result to MIDI or WAV.

**Key features:**

* Local AI inference with Rust and Candle
* Desktop interface built with Iced
* Configurable instruments, tempo, key and sampling parameters
* Built-in playback and MIDI/WAV export
* Automated tests, CI and license checks
* Releases for Linux, Windows and macOS
